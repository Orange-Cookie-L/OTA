# STM32 ESP8266 OTA 系统部署与固件上传指南

## 一、系统部署

### 1. 服务器部署

#### 1.1 环境准备
- **操作系统**：Windows、macOS或Linux
- **Python版本**：3.7或更高
- **网络环境**：稳定的局域网

#### 1.2 安装依赖
1. **打开命令提示符**（Windows）或**终端**（Mac/Linux）
2. **进入server目录**：
   ```bash
   cd c:\Users\admin\Desktop\项目\server
   ```
3. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```

#### 1.3 启动服务器
1. **运行服务器**：
   ```bash
   python server.py
   ```
2. **服务器启动成功后**，会看到类似以下输出：
   ```
   * Serving Flask app 'server'
   * Debug mode: off
   WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
   * Running on all addresses (0.0.0.0)
   * Running on http://127.0.0.1:5000
   * Running on http://192.168.1.100:5000
   Press CTRL+C to quit
   ```
3. **记录服务器地址**：如 `http://192.168.1.100:5000`

### 2. 硬件部署

#### 2.1 硬件连接
| STM32F103C8T6 | ESP8266 | 说明 |
|---------------|---------|------|
| PA9 (TX)      | RX      | 串口通信（STM32发送 → ESP8266接收） |
| PA10 (RX)     | TX      | 串口通信（STM32接收 ← ESP8266发送） |
| GND           | GND     | 共地 |
| 3.3V          | 3.3V    | 供电（注意：ESP8266峰值电流可能较大，建议单独供电） |
| GPIOC13       | -       | LED正极（负极接GND） |

#### 2.2 烧录固件

##### 2.2.1 烧录ESP8266固件
1. **配置ESP8266代码**：
   - 打开 `esp8266/src/main.cpp`
   - 修改WiFi配置和服务器地址：
     ```cpp
     const char* ssid = "your_ssid";     // 你的WiFi名称
     const char* password = "your_password"; // 你的WiFi密码
     const char* ota_server = "http://192.168.1.100:5000"; // 服务器IP地址
     ```
2. **使用PlatformIO编译并烧录**

##### 2.2.2 烧录STM32固件
1. **编译Bootloader**：
   - 编译 `stm32/bootloader/Src/bootloader.c`
   - 烧录到地址 `0x08000000`

2. **编译应用程序**：
   - 编译 `stm32/Core/Src/main.c`
   - 烧录到地址 `0x08004000`

## 二、固件上传

### 1. 固件准备

#### 1.1 固件类型
- **STM32 固件**：二进制文件（`.bin`），大小不超过 112KB
- **ESP8266 固件**：二进制文件（`.bin`）

#### 1.2 固件命名规范
建议按照以下格式命名固件文件：
```
[设备类型]_[版本号].bin
```
例如：
- `stm32f103c8t6_1.0.0.bin`
- `esp8266_1.1.0.bin`

#### 1.3 使用 Keil 生成二进制文件

1. **配置 Keil 项目**：
   - 打开 STM32 项目（`.uvprojx` 文件）
   - 点击菜单栏的 `Options for Target`（或按 `Alt+F7`）
   - 在 `Output` 选项卡中勾选 `Create HEX File`
   - 在 `User` 选项卡的 `After Build/Rebuild` 区域，勾选 `Run #1` 并输入：
     ```
     fromelf --bin -o "$L@L.bin" "#L"
     ```

2. **编译项目**：
   - 点击工具栏的 `Build` 按钮（或按 `F7`）
   - 编译完成后，在项目目录的 `Output` 文件夹中会生成 `.bin` 文件

3. **确认固件大小**：
   - 确保生成的 `.bin` 文件大小不超过 112KB
   - 可以在文件属性中查看文件大小

### 2. 上传步骤

#### 2.1 登录服务器
1. 在浏览器中打开服务器地址（如 `http://192.168.1.100:5000`）
2. 使用管理员账号登录：
   - 用户名：admin
   - 密码：admin123

#### 2.2 上传固件
1. **进入固件管理页面**：在导航栏中点击“固件管理”
2. **填写固件信息**：
   - 选择固件文件（`.bin`）
   - 输入版本号（如 `1.0.0`）
   - 选择设备类型（如 `stm32f103c8t6`）
3. **点击“上传”按钮**
4. **确认上传成功**：页面会显示已上传的固件信息

### 3. 固件更新流程

1. **设备检查更新**：
   - STM32定期（默认60秒）发送检查更新请求
   - ESP8266向服务器查询最新固件版本

2. **固件下载**：
   - 如果有新版本，ESP8266从服务器下载固件
   - 分块传输给STM32（默认64字节/块）

3. **写入闪存**：
   - STM32接收数据并写入闪存
   - 每块数据传输后发送确认

4. **更新完成**：
   - 传输完成后，STM32重启
   - Bootloader验证新固件并跳转到新固件运行

## 三、系统验证

### 1. 设备注册验证
1. **启动设备**：连接电源，启动STM32和ESP8266
2. **检查服务器**：在服务器的“设备管理”页面查看设备是否注册成功
3. **查看设备状态**：确认设备显示为“在线”状态

### 2. 固件更新验证
1. **上传新固件**：在服务器上传新版本固件
2. **观察设备**：
   - LED快速闪烁表示正在下载固件
   - 下载完成后设备会重启
3. **验证更新**：在服务器的“设备管理”页面查看设备的固件版本是否更新

## 四、故障排除

### 1. 服务器相关问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 服务器无法启动 | 端口被占用 | 修改 `server.py` 中的端口号 |
| 无法访问服务器 | 防火墙阻止 | 允许Python通过防火墙 |
| 登录失败 | 密码错误 | 使用默认密码 `admin123` |

### 2. 设备相关问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 设备无法注册 | 串口连接错误 | 检查TX/RX引脚连接 |
| 设备无法连接WiFi | WiFi配置错误 | 检查WiFi名称和密码 |
| 固件下载失败 | 网络连接不稳定 | 确保网络连接稳定 |
| 设备无法启动 | 固件损坏 | 重新上传固件 |

### 3. 固件上传问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 上传失败 | 文件大小超过限制 | 确保固件大小不超过112KB |
| 设备无法检测到新固件 | 版本号格式错误 | 使用语义化版本号（如 `x.y.z`） |
| 固件更新失败 | 固件与设备不匹配 | 确保固件与设备类型对应 |

## 七、常见问题解答

**Q: 服务器需要一直运行吗？**
A: 是的，服务器需要一直运行才能处理设备的注册、心跳和固件更新请求。

**Q: 设备离线后重新上线会自动更新吗？**
A: 是的，设备重新上线后会自动检查更新并下载最新固件。

**Q: 可以同时更新多个设备吗？**
A: 是的，服务器支持同时处理多个设备的更新请求。

**Q: 固件更新过程中断电会怎样？**
A: 断电可能导致固件损坏，设备会进入Bootloader模式等待重新下载固件。

**Q: 如何查看设备的更新状态？**
A: 在服务器的“设备管理”页面可以查看设备的状态和固件版本。
